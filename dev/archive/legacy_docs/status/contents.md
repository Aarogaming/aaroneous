**Rationale**: Fixes are independent → phases can run sequentially without blocking
**Benefit**: Clear gates between phases, easy rollback if needed

### Decision 2: Weekly Gates
**Rationale**: Ensures progress is real (tests pass) before moving forward
**Benefit**: Catches issues early, prevents cascading failures

**Rationale**: Coherent integration requires single person seeing full architecture
**Benefit**: Consistent vision, no contradictory changes

### Decision 4: Integration Tests First
**Rationale**: Tests verify real integration, not just compilation
