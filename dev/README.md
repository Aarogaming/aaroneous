# Aaroneous Developer & Maintenance System (`dev`)

Welcome to the **`dev`** project. This directory serves as the permanent homebase, centralized headquarters, and immutable foundation for all documentation, forensic analysis, diagnostic tooling, maintenance harnesses, and architectural specifications for the **Aaroneous** Synthetic Intelligence platform.

---

## 🧭 Core Directives

1. **Homebase Bedrock (`dev/`)**: Everything within `dev/` is the authoritative source of truth. Everything outside of `dev/` is treated as a malleable, modular substrate to be deconstructed, reorganized, and reconstructed.
2. **The Programmatic Stem Cell**: Aaroneous is engineered as a pluripotent meta-programming substrate—"the program that programs with programs"—capable of differentiating into specialized computational organs on demand.
3. **Automated Software Wrapping & Adaptation**: External target programs (CLI utilities, native DLLs, APIs, GUI apps) are ingested, deconstructed by Chimera, probed by Marionette, and automatically wrapped with Machine-Native Linking Protocol (MNLP) harnesses to become first-class cooperative utilities.
4. **Omni Galaxy 3D Semantic Access**: Data and capabilities are navigated not through physical filesystem folders, but as a 3D galaxy of content-related star-nodes and gravitational clusters.
5. **Synthetic Intelligence (SI) over Human-Token AI**: Machines communicate in machine-native representations (binary vectors, tensor matrices, shared memory mmap, structured binary IPC). Human language is strictly an edge translation skill for human-machine interaction.
6. **The Specialist Federation**: A simplified, modernized family of 9 Sovereign Specialists (Odin, Merlin, Ariel, Hephaestus, Argus, Dionysus, Hermes, Wen, Kami) operating paired autonomous Relic Substrates without bulky legacy city/location metaphors.
7. **Phase Out WASM**: Eliminating WebAssembly and WIT virtualization overhead across the entire stack in favor of high-performance native machine code.
8. **Absolute Host Safety**: Zero unconstrained OS-level input injections or unthrottled desktop screen grabbing during development or testing.

## 🛠️ Tool Suite (`tools/`)

### Omni 3D Galaxy Navigation (`tools/omni/`)
- [`omni_spatial_projector.py`](file:///d:/Aaroneous/dev/tools/omni/omni_spatial_projector.py): Projects any codebase or dataset into 3D semantic star-nodes and gravitational galaxy clusters.

### Auto-Wrapping & Morphogenesis (`tools/auto_wrapper/`)
- [`generate_wrapper.py`](file:///d:/Aaroneous/dev/tools/auto_wrapper/generate_wrapper.py): Synthesizes native Rust MNLP adapter harnesses for any target executable or DLL.

### Diagnostics (`tools/diagnostics/`)
- [`host_safety_monitor.ps1`](file:///d:/Aaroneous/dev/tools/diagnostics/host_safety_monitor.ps1): Scans for rogue background processes, locked ports, and memory leaks.
- [`inspect_codebase.py`](file:///d:/Aaroneous/dev/tools/diagnostics/inspect_codebase.py): Audits all first-party `Cargo.toml` crates and detects missing workspace members.
- [`check_ports_and_locks.ps1`](file:///d:/Aaroneous/dev/tools/diagnostics/check_ports_and_locks.ps1): Checks status of ports 8765, 4222, and `.synapse` mmap handles.

### Maintenance (`tools/maintenance/`)
- [`purge_stale_synapse.ps1`](file:///d:/Aaroneous/dev/tools/maintenance/purge_stale_synapse.ps1): Safely releases locked memory-mapped files (`primary.synapse`) in `AppData\Local\Temp`.
- [`clean_workspace.ps1`](file:///d:/Aaroneous/dev/tools/maintenance/clean_workspace.ps1): Cleans stale build artifacts, unlinked target caches, and temporary data.
- [`deconstruction_triage.py`](file:///d:/Aaroneous/dev/tools/maintenance/deconstruction_triage.py): Scans and triages all files into the 5 sovereign destination buckets.

### Safe Runners (`tools/runners/`)
- [`launch_safe_mode.ps1`](file:///d:/Aaroneous/dev/tools/runners/launch_safe_mode.ps1): Executes Aaroneous with `--no-hid` and sandboxed mock frame capture.
- [`dev_env_check.ps1`](file:///d:/Aaroneous/dev/tools/runners/dev_env_check.ps1): Verifies presence and versions of Rust, Node, Python, and NATS.

### Protocols (`tools/protocol/`)
- [`linking_protocol_spec.json`](file:///d:/Aaroneous/dev/tools/protocol/linking_protocol_spec.json): Machine-readable schema for inter-program tensor and command packets.
