## Deployment Options

### 1. Local Development
```bash
docker-compose up -d
# 9 services, full development environment
```

### 2. Single Node
```bash
docker run -d \
  -p 8001:8001 \
  -e DATABASE_URL=... \
  -e REDIS_URL=... \
  aaroneous-federation:1.0.0
```

### 3. Kubernetes
```bash
helm install aaroneous-federation aaroneous/aaroneous-federation \
  -f values.yaml \
  -n aaroneous --create-namespace
```

### 4. Cloud (AWS/GCP/Azure)
```bash
terraform apply -var-file=environments/production.tfvars
helm install aaroneous-federation ...
```

### 5. Mobile (iOS/Android)
```bash
# iOS
xcodebuild -scheme Aaroneous -configuration Release

# Android
./gradlew assembleRelease
```
